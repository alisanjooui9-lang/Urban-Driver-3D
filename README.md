هدف پروژه

هدف Urban Driver 3D ساخت یک تجربه رانندگی سه‌بعدی گسترده و قابل توسعه است که بازیکن بتواند علاوه بر رانندگی، با خودرو، شخصیت، شهر، مسافر، بار و گاراژ تعامل داشته باشد.
